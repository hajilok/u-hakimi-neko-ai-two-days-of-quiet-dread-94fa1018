## How It Runs

`main.ts` runs on Node 22 (standard library only, zero external dependencies, deterministic byte-exact output) and writes a single-line UTF-8 code review approval comment (<= 140 characters) to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when testing locally).

```bash
mkdir -p /tmp/out && MAKEFUN_OUTPUT_DIR=/tmp/out node main.ts && cat /tmp/out/entry.txt
```
